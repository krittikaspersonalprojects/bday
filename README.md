# A birthday surprise

A small, dependency-free birthday website. Open `index.html` in a browser to start, or serve this folder with any static file server.

## Personalize it

- Replace the 21 example strings in the `reasons` array in `script.js`.
- Replace `YOUR_SPOTIFY_PLAYLIST_LINK` in `songs.html` with the Spotify playlist URL.
- Replace the bracketed prompts in the letter dialog in `letter.html` with your note.
- Update the greeting in `index.html` if you would like to add his name.

The site works on mobile and desktop. No build step or package installation is needed.
